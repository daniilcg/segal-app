Что это

SEGAL — это закрытый мессенджер от SEGAL COMMUNICATIONS. Он нужен не для всех подряд, а для небольшого круга людей, которым вы доверяете: родных, близких, тех, с кем важно общаться спокойно и без лишних глаз.

Для чего

  • Сообщения — обычный чат, но с шифрованием на устройстве.
  • Звонки — аудио и видео прямо из приложения.
  • Приватность — сервер не хранит текст ваших сообщений в открытом виде.
  • Простота — скачали, установили, вошли и пользуетесь.

Android

  1. Нажмите Скачать для Android и дождитесь файла.
  2. Откройте скачанный SEGAL.apk и разрешите установку, если телефон спросит.
  3. При первом запуске разрешите уведомления — так не пропустите звонок.
  4. Создайте аккаунт или войдите. Дальше просто пишите и звоните своим.

iPhone

Как приложение (IPA) — нужен ПК с Windows один раз:

  1. Скачайте Скачать для iPhone (файл SEGAL.ipa).
  2. На компьютере установите Sideloadly.
  3. Подключите iPhone кабелем → в Sideloadly выберите IPA и свой Apple ID → Start.
  4. На iPhone: Настройки → Основные → VPN и управление устройством → доверить.

Без компьютера — иконка с сайта:

  1. Откройте segal.mplcrm.com в Safari.
  2. Поделиться → На экран «Домой» → Добавить.
